# 术语统一口径（glossary）

本仓库统一使用以下术语口径，避免同一概念多写法造成漂移。正文与分发物均遵守。

| 术语 | 统一含义 | 备注 |
| --- | --- | --- |
| 薄肌（lean muscle） | 低体脂、线条清晰、精瘦而有力量的身体状态；“瘦体重/肌肉管理”理念 | 与「骨感瘦 / skinny」严格区分，见下方「瘦 ≠ 薄肌」 |
| 瘦（单纯减重） | 单纯的低体重、苗条，甚至伴随肌肉流失；以「体重数字下降」为唯一指标 | 对比图中左栏定义 |
| 搏击 | 仅用于术语说明与电影专名《搏击俱乐部》 | 不用于指代本项目训练内容；训练动作体系见 `guides/8-week-plan/` |
| 渐进超负荷 | Progressive Overload：训练中逐步增加负荷以持续刺激肌肉增长 | 加量规则见 `guides/8-week-plan/README.md` |
| 三步启动法 | 访谈公开解读中对启动薄肌训练的概括（未披露逐周动作明细） | 书中口径，非逐周训练方案 |

## 瘦 ≠ 薄肌

- 瘦：节食与极端控食，伴随肌肉流失；缺乏力量储备，可能免疫力下降、激素紊乱。
- 薄肌：力量训练 + 营养管理 + 恢复，低体脂约 12%–15%、线条清晰、精瘦而有力量。
- 可视化对比见 [assets/lean-vs-thin.png](../assets/lean-vs-thin.png)。
